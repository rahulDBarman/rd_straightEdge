# Maya Straight Edge Script

The **Straight Edge Script** is designed to simplify edge alignment in Maya 3d modeling.  
It allows artists to quickly straighten selected edges, improving precision and speeding up the modeling workflow.  
This tool is especially useful for creating clean geometry and maintaining consistent topology in complex meshes.

### Edge slide mode
```commandline
rd_straight_edge(scale_value=0.4, slide = True)
```

### Straight mode
```commandline
rd_straight_edge(scale_value=0.4, slide = False)
```
